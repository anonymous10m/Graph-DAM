# Graph-DAM

> **Anonymous review repository.** This snapshot contains no author names, affiliations, personal links, or commit metadata.

Code and figures for **Graph-DAM**, a dense associative memory framework for graph-structured data based on graph Laplacians and an operator-norm / Dirichlet-energy geometry.

This repository contains six experiments used to illustrate the method:

1. Graph LSE energy landscape on sampled SBM Laplacians.
2. Synthetic SBM community-network retrieval.
3. Real-world airline-network retrieval using `nycflights13`.
4. Real-world protein-conformation retrieval using experimental NMR structures from the RCSB Protein Data Bank.
5. Real-world smartphone human-activity retrieval using the UCI HAR dataset.
6. Real-world distributed wearable-sensor retrieval using the UCI Daily and Sports Activities (DSA) dataset.

## Overview

Graph-DAM stores graph Laplacians and scores a query through an operator-norm discrepancy. The experiments compare this graph-aware retrieval geometry with Euclidean DAM baselines that vectorize the Laplacian, and, for the real-data experiments, with Euclidean baselines on the original data representation.

## Energy landscape

The graph LSE landscape is visualized on the first two PCA directions of sampled SBM Laplacians. As the inverse temperature increases, distinct basins form around stored graph memories.

![Graph LSE energy landscape](figures/energy_landscape.png)

## Synthetic SBM retrieval

The SBM experiment stores 50 graph memories on 120 nodes with four communities and evaluates retrieval after masking 20% of existing edges. Graph-DAM is compared with Eu-DAM applied to the same Laplacians.

![SBM retrieval accuracy](figures/sbm_retrieval_accuracy.png)

## Airline-network retrieval

The airline experiment uses the public [`nycflights13`](https://nycflights13.tidyverse.org/) data. January--June flights define stored carrier networks and July--December flights define temporally held-out queries. The networks use a common set of frequently occurring airports and weighted edges given by flight counts.

![Airline retrieval accuracy](figures/airline_retrieval_accuracy.png)

## Protein-conformation retrieval

The protein experiment uses experimental NMR ensembles downloaded from the [RCSB Protein Data Bank](https://www.rcsb.org/). Each protein memory averages the contact-network Laplacians from six experimental NMR conformations. Queries are built from completely held-out conformations and corrupted by uniformly masking 20% of existing non-backbone contact edges while preserving the full residue set and backbone connectivity. Protein conformations are represented by weighted residue contact networks constructed from C-alpha coordinates.

![Protein retrieval accuracy](figures/protein_retrieval_accuracy.png)

## UCI HAR human-activity retrieval

The UCI HAR experiment constructs 60-node temporal-sensor graphs from six synchronized smartphone inertial channels. Each activity interval is divided into ten temporal blocks, with one node for each sensor channel within each block. Edge weights encode absolute waveform correlations and queries are generated by masking 20% of existing graph edges. Graph-DAM is compared with Eu-DAM on the same vectorized Laplacians and Raw Eu-DAM on conventional non-graph sensor features.

![UCI HAR retrieval accuracy](figures/har_retrieval_accuracy.png)

## UCI Daily and Sports Activities retrieval

The DSA experiment uses inertial sensors distributed across the torso, right arm, left arm, right leg, and left leg. Each stored recording is represented by a 45-node body-sensor graph (five body locations times nine sensor channels). Edges encode cross-channel temporal correlations, giving a direct relational representation of coordinated whole-body motion. Queries mask 20% of existing graph edges. Graph-DAM is compared with Eu-DAM on the same Laplacians and Raw Eu-DAM on compact sensor features.

![DSA retrieval accuracy](figures/dsa_retrieval_accuracy.png)

## Data

The synthetic experiments generate their data directly in code. The airline script downloads the required `nycflights13` tables. The protein script downloads the required PDB structures from RCSB PDB. The HAR and DSA scripts automatically download their respective UCI datasets.
